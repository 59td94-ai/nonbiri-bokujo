# つなげて作る文の洗い出し（2026-11-25）

画面に出た文を集める方法（i18n_crawl）では、テロップやお知らせなど「名前や数字をつなげて作る文」を取りこぼしていたので、
プログラムから直接洗い出す道具を作った。

1. `node ext2.js ../../index.html all.json` … script の中の文字列と「"…"+変数+"…"」の形をすべて取り出す（acorn を使用）
2. `python3 seg2.py` … HTML のタグで区切り、変数の部分を {1}{2}… にした「ひな形」にする（segs2.json）
3. `python3 rt2.py out.json` … 英語モードで実際に訳してみて、日本語が残るものだけ書き出す（変数には ¥1,200・キャベツ・12 などの見本を入れる）

訳は `i18n/en.json` の `pat`（{1}{2}… にどんな文字列でも入るひな形）と `text` に入れる。
pat の仕組みは `tools/patch_pat.py`。
