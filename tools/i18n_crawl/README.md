# 英語の訳もれ探し（開発用。ゲームには含まれない）

ヘッドレス Chrome（playwright）でゲームを英語モードで自動操作し、訳されなかった日本語を集める。
パスは作業環境（/home/claude/...）に合わせてあるので、使うときは直す。

- `python3 -m http.server 8765`（リポジトリ直下で起動）
- `monkey.py 種 秒数 セーブ.json 出力.json`：ランダムに押して回り、訳もれ（`window.__lsMiss`）を集める
- `pending.py`：集めた訳もれから、まだ en.json にないものを一覧にする（タイプライター表示の途中の文は除く）
- `conv.py`／`merge.py`：「日本語 ||| English」の行を en.json に足す（# は {1}{2}… に置きかえ）
- `verify.py`：各タブのスクリーンショットと画面の文字を保存（日本語版が変わっていないかの確認にも使う）
- `save_lv253.json`：確認用のセーブ（Lv.253・所持金たっぷり）
