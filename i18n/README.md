# 英語対応（i18n）

英語モードの訳は `i18n/en.json` にまとめ、`tools/build_en.py` で `index.html` に埋め込みます。
日本語・中国語・韓国語の表示には影響しません（英語を選んだときだけ使われます）。

## ファイル
- `i18n/en.json`
  - `nouns`：名前（作物・製品・施設・キャラ・従業員の名前など）
  - `text`：画面の文。数字は `{1}{2}…` に置きかえたキー
- `tools/patch_runtime.py`：多言語スクリプトに追加辞書を読む処理を足す（1回だけ実行済み）
- `tools/build_en.py`：`en.json` を `index.html` に埋め込む（訳を直したら毎回実行）

## しくみ（英語のとき）
1. 前からある辞書（TXT／TPL）で引けなければ、`en.json` を引く
2. 文の中に `nouns` の名前があれば `{A}{B}…` に置きかえた「ひな形」で引く
   （build のときに、例の文からひな形を自動で作る。例：「小麦の種を3袋 買いました！」→ どの作物でも訳される）
3. 先頭の絵文字だけ違う文は、絵文字を外した形でも引く
4. 「・」「（）」などで区切られた文は、区切りごとに訳せればつなげて表示

## 訳を足す・直す
```
# en.json を直す
python3 tools/build_en.py
```
